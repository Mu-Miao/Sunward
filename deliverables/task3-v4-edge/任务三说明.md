# 任务三 V4 EDGE

基线：main `4c516f08a1a215a9e11f860531db7c200157862d`，任务二 V22 / 任务四 V19 EDGE。分支：`codex/task3-edge-one-lap`。

任务三使用任务四配置的独立值副本，仅将单圈核心超时设为 40000ms。任务四仍从原基础参数生成配置，避免循环调用，也避免任务三覆盖任务四的超时。任务三直接运行核心，不调用任务四的四圈包装层，返回 A 后停稳并 DONE；A、C、B、D、A 共五次点位提示。中间换段采用连续运动，内轮保持前进目标。

同步开放任务三在适配层的 EDGE 输出、可信失线方向、连续换段积分重定向及弧内边缘降速。保留 STOP、OFF、传感器、低压、节拍、轮速、反转、堵转及线路边界保护。40 秒包含最终停稳阶段，超时优先停车。

任务二与任务四保持基线行为：Task4 配置全部字段与基线逐项比较一致；同一主机回放输入下，Task2/Task4 启动后的 GPIO、电机、OLED、UART 与调度状态轨迹哈希分别为 `2598d92837a25067` / `0f0336a4beee21fd`，修改前后一致。日志随交付包提供。这是主机模拟比较，不是实车测量。

验证运行 `python3 tools/tests/run_tests.py --sanitize`，涵盖 CarApp 和兼容入口。新增实际 Task3 默认配置回归：目标轮速跟随模拟下，一圈 31570ms、四次转向、两个半圆、五次提示、中间零停车；验证 EDGE 左右外侧接管、短白区恢复、持续失线、40 秒超时及保护优先级。历史停稳配置测试通过显式基础配置保留，不作为新版 Task3 的运行入口。

固件以 `python3 tools/build_firmware.py` 构建。当前修改仅经过软件回归和 ARM 构建，未烧录，未实车验收。任务二、四原有实车结果属于原版本记录。

操作保持：A 点朝 B 摆放；OFF 且空闲时长按 PA0 选到 TASK 3，短按静态 CAL，READY 后 ON 并按键启动。
