# V16 CONT：任务四全程连续换段、双轮前进转向

2026-10-20，用户反馈巡线开始、巡线结束仍停顿，要求正常路线全部不停、转向两轮都转。V15只取消了C/D入弧前的停车等待，A/B和圈间A点仍使用停止流程；V16一并改为连续运动。18组主机回归、ARM构建通过，本轮未连接探针或烧录，实际轨迹尚未验证。

## 正常运动

- 任务四开启`DPT_TASK4_CONTINUOUS=1`，任务三保留原流程。
- A启动、B转BD、C/D转切线均为两轮正向速度目标：内轮20mm/s，外轮80mm/s；接近目标角时仅减外轮，最低55mm/s，保留至少35mm/s差速。±3°连续30ms移动确认后直接进入直线或捕线，无需静止，不经过START_SETTLE、VERTEX_BRAKE或ALIGN_SETTLE。
- C/D仍在原距离窗口内低速确认有效线，捕线→入弧→巡线当拍持续输出前进目标。B/A巡线出口仍须满足里程窗口、末端航向和连续全白30ms；确认期间以50mm/s保持末端切线，确认后直接转向下一段。
- 前三圈A出口确认后立即计圈、接续下一圈转AC，保留首次AC参考，不重复发启动提示。第四圈仍停车、停稳后报告DONE。四圈共8次入弧、17次点位提示。
- 弧段可信全白桥接及重新见线的30ms恢复确认均低速移动；未确认的图样不会更新冻结的寻找方向，也不能重置原失线预算。C/D顶点全白搜索也改为移动对正/确认，原搜索边界保留。
- 不清除正常换段时的轮速PI，避免当拍输出零驱动。两轮正目标由编码器闭环跟踪；减速时PI可能输出零让车滑行，实际是否持续转动仍取决于电机和地面，软件回归不能代替实测。

## 参数与保护

双轮前进转向的弯曲半径大于原单轮转向。任务四转向位移预算由80mm调整为120mm，每次转向4秒限制保留；任务三仍为80mm。按160mm轮距、80/20mm/s计算，平均转弯半径约133mm，38.66°转向名义移动约90mm，原80mm预算不足，故需配套调整。

任务四输出上限2200、直线270mm/s、巡线240mm/s、入弧50mm/s、边缘降速120mm/s、B→BD少转3°保持前版参数。没有提高速度保护或全局PI增益。

STOP/OFF、低压、ADC/IMU/RX故障、节拍、超速、反转、堵转、转向/捕线/路线边界、失线及160秒总超时仍能停车。全黑、不连续黑线或缺少可信历史的失线仍停止输出，不能因“全程不停”而沿未知方向继续跑。
