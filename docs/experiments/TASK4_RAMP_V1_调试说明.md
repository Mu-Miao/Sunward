## 修改内容

任务四新增独立配置 `DPT_TASK4_ARC_ACCEL_MMPS2=50.0f`，原先为沿用任务三的 100 mm/s²。起步速度仍为 50 mm/s，半圆巡航仍为 200 mm/s；无其他限速时，加速时间由约 1.5 秒变为约 3 秒。半圆失线恢复后的加速同样受此慢斜坡约束。各圈 CB、DA 均应用该配置。

任务一、二、三的运动参数、现有转向目标、巡线增益与差速上限保持。边缘降速、连续有效确认、300 ms / 20 mm / 12° 寻线预算及总 160 秒保护保持。任务四 OLED 标题改为 `TASK 4 RAMP V1`，任务三仍为 `TASK 3 SEEK V1`。

F7 停车后增加第三页诊断，三页每两秒轮换：

1. `LF… PRE…` 与 `P8 F7 S… Y…`：首次失线快照与段里程。
2. `E… C… PRE…` 与 `T…/… V…/…`：最后有效纠偏与首次失线轮速。
3. `CB LIMIT TIME/DIST/ANGLE/MULTI` 与 `MS… D… A…`：触发保护的限制，以及本次失线持续时间（ms）、平均编码器位移（mm）、航向变化（°）。`MULTI` 表示同一采样触发多个限制；`DIST` 也包含原有反向位移限制。

第三页的数据在触发 F7 时锁存，区别于前两页的首次失线快照。诊断不放宽保护，也不改变停车后的锁存行为。
